The problem

Training shouldn't depend on who's teaching

Today

  • The training lives in a deck or a binder nobody can open mid-session
  • New trainers shadow for weeks before they can run a session alone
  • Steps get skipped, so people leave with gaps and come back with tickets

With PromptVu

  • Each step sits on the screen where it happens, in the order it should happen
  • New trainers run the session from day one with the script in front of them
  • Every session covers every step, so people leave ready to do the work
