# Map the demo

Good prompts sit on the right element and tie it to a buyer outcome. You can't do that without knowing the product's screens. This skill builds that map once per product.

Before you start, read `references/working-in-promptvu.md`.

## Step 1: Get access and pick the sequence

1. Follow "How to get in" in `references/working-in-promptvu.md`.
2. Ask the rep which sequence is their main demo, unless the knowledge base already says.
3. Open Prompt Sequences and find it. If it doesn't exist yet, ask the rep for the Start URL and the order they usually click through.

## Step 2: Walk it

Press Play on the sequence. Click through the product the way the rep demos it. PromptVu follows the page you're on, so never type URLs.

**Only click to navigate.** Never submit forms, save settings, or create or delete anything in the product. If a step needs data entry to continue, stop and ask the rep how they handle it on a live call.

## Step 3: Record each page

For each page or screen, record:

| Field | What to write |
|---|---|
| # | Order in the demo |
| Page | A plain name, like "Pricing" or "Pipeline dashboard" |
| URL | As shown, for reference only |
| What it shows | One line |
| Key elements | The buttons, charts, prices, tables or headings the rep would point at |
| Buyer outcome | Which result this page proves: time saved, revenue gained, costs cut or risk reduced |
| Existing prompts | How many prompts are already on it |
| Same-URL screens | Any tab, pop-up or wizard step that changes the screen without changing the URL |
| Notes | Login walls, slow loads, empty states, anything that could trip up a live demo |

## Step 4: Flag what matters

After the table, list:

- Screens that change without the URL changing. Prompts there may show on the wrong screen.
- Pages with no clear buyer outcome. Suggest whether to keep or skip them.
- Text boxes the rep points at. Prompts there have to be added from the PromptVu Manager, not by right-click.
- Anything that looked broken or empty.

## Step 5: Save it

Add the map to the rep's "[PRODUCT] knowledge base" under "Demo map". Show the rep the table and fix anything they correct.

## Done

Tell the rep how many pages you mapped, which ones carry the most ROI, and anything you flagged.
