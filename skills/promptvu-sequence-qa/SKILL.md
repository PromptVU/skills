# Check a Prompt Sequence

Read first: `references/rules.md` and `references/writing-prompts.md`.

Steps in the PromptVu app are written as **bold actions**. How to do each one is in `references/promptvu-app.md`.

This skill only reviews. Don't change prompts unless the rep asks. If they do, work in a duplicate unless they say otherwise.

## What to do

### 1. Read it
**Get into PromptVu**, **Find a sequence** (the one the rep names) and **Read all prompts**. Note each prompt's number, page and text.

### 2. Score every prompt
Check each prompt against `references/writing-prompts.md` and the rep's knowledge base:

| Check | Passes when |
|---|---|
| Voice | Sounds like the rep, not a generic script |
| Length | One or two sentences the rep can say at a glance |
| ROI | Ties the screen to time, revenue, cost or risk |
| Specific | Has a number, an outcome or a question |
| Facts | Every claim is in the knowledge base or the buyer's own words |
| Buyer fit | Matches the buyer this copy is for, if it's tailored |
| Unique | No two prompts on the same page have identical text |

### 3. Play it through
**Play a sequence** and **Check placement** for every prompt, in order:

- Does it show on the element it talks about?
- On screens that change without the URL changing, does it show on the right screen?
- If one is missing, **Reset a missing prompt** and note where it belongs.

Only click to move around in the product. Don't submit or change anything.

### 4. Report
Give the rep:

1. **Verdict:** ready, ready with fixes or not ready
2. **Must fix:** wrong facts, wrong placement, missing prompts
3. **Should fix:** weak prompts, with a suggested rewrite for each
4. **Flow:** pages you'd reorder, skip or add for this buyer
5. **Count:** prompts checked, passed, flagged

Offer to make the fixes in a duplicate.

## Actions used in the app
