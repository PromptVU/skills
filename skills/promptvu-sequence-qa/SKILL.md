# QA a Prompt Sequence

Before you start, read `references/working-in-promptvu.md` and `references/writing-prompts.md`.

By default this skill only reviews. Don't change prompts unless the rep asks you to fix them. If they do, work in a duplicate unless they say otherwise.

## Step 1: Open it

1. Follow "How to get in" in `references/working-in-promptvu.md`.
2. Open Prompt Sequences and the sequence the rep names.
3. Read "List of all prompts" and note each prompt's number, page and text.

## Step 2: Score every prompt

Check each prompt against `references/writing-prompts.md` and the rep's knowledge base:

| Check | Pass when |
|---|---|
| Voice | Sounds like the rep, not a generic script |
| Length | One or two sentences the rep can say at a glance |
| ROI | Ties the screen to time, revenue, cost or risk |
| Specific | Has a number, an outcome or a question |
| Facts | Every claim is in the knowledge base or the buyer's own words |
| Buyer fit | Matches the buyer this copy is for, if it's tailored |
| Unique | No two prompts on the same page have identical text (they can merge on save) |

## Step 3: Play it through

Press Play and click each prompt in the PromptVu Manager, in order. For each:

- Does it show on the element it talks about?
- On screens that change without the URL changing, does it show on the right screen?
- Is anything missing? Use the reset button in the PromptVu Manager, then note where it belongs.

Only click to navigate in the product. Don't submit or change anything.

## Step 4: Report

Give the rep:

1. **Verdict:** ready, ready with fixes, or not ready
2. **Must fix:** wrong facts, wrong placement, missing prompts
3. **Should fix:** weak prompts, with a suggested rewrite for each
4. **Flow:** pages to skip, reorder or add for this buyer
5. A one-line count: prompts checked, passed, flagged

Offer to make the fixes in a duplicate.
