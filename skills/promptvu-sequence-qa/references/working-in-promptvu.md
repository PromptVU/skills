# Working in PromptVu

Read this before you touch PromptVu. The full guide is at https://promptvu.com/ai-guide.html (plain text: https://promptvu.com/llms-full.txt).

## How to get in

- If you have a PromptVu connector (tools whose names start with "promptvu"), use it and skip the screen. It reads sequences and saves your changes as drafts the rep approves in the app.
- Otherwise, PromptVu is a desktop app on the rep's computer, not a website. Don't look for it in a web browser.
- Request access to the PromptVu app before anything else, using your computer control (computer use in Claude, Work mode in ChatGPT). Wait for the rep to approve.
- Today PromptVu needs full-screen control. If you're offered a choice, ask for full control, not background mode.
- The rep is already signed in. Never ask for their password. If PromptVu is closed or signed out, stop and tell the rep.

## Key terms

- **Prompt:** a short script attached to an exact spot on a web page. It tells the rep what to show and what to say at that moment.
- **Prompt Sequence:** a whole demo. The prompts, in order, across every page the rep presents, starting from a Start URL.
- **PromptVu Manager:** the panel on the right while a sequence plays. It lists every prompt in order. Click a prompt to jump to its page.
- **LIVE CONTROL window:** the rep's private window. Never share it.
- **Presenter Screen:** the clean copy the rep shares on the call. It never shows prompts.

## Where things are

- The dashboard is at promptvu://promptvu-dashboard, inside the app. The left menu has Prompt Sequences, Projects, AI Prompt Agent, Outbound, Admin Settings and Settings.
- Each sequence row has Play, Duplicate, Settings, Share and Delete.
- Click a sequence name to see "List of all prompts". Each prompt has a pencil to edit it.

## PromptVu follows the page you're on

- When you click to a new page during a sequence, that page's prompts appear on their own. A new prompt saves to the page you're on.
- Never type URLs. Navigate by clicking, the way the rep would on a call.
- Only edit a prompt's URL to move it to a different page.
- Some screens change without the URL changing (tabs, pop-ups, wizard steps). Check those prompts during the play-through and tell the rep about any that land on the wrong screen.

## Common tasks

- **Duplicate first:** click Duplicate on the sequence, then rename the copy for the buyer, like "Platform demo - CFO". Change only the copy.
- **New sequence:** check the Prompt Sequences list first. If one exists for this demo, duplicate it. Otherwise click "+ New Prompt Sequence", enter a name and the Start URL, leave "Autogenerate prompts with AI" unchecked and click Save.
- **Edit text:** in the PromptVu Manager, click the prompt, click Edit, change the text and click Save. Or use the pencil in "List of all prompts" and click Save Changes.
- **Add on the page:** play the sequence, click through to the page, right-click the exact spot and choose Insert presenter note.
- **Add from the Manager:** click the plus button, write the text, click Save Note, then drag the new prompt from the upper right corner to its spot.
- **Text boxes:** right-click doesn't work on text boxes and other input fields yet. Add from the Manager and drag it next to the field.
- **Missing prompt:** click its reset button in the PromptVu Manager. It moves to the upper right corner. Drag it back.

## Rules

- Inside PromptVu, only work on the sequence the rep names. Outside PromptVu, only read: research what you need, but don't sign in, submit or change anything.
- In the product being demoed, only click to navigate. Never submit forms, change settings, or create or delete anything there.
- Never delete a sequence or a prompt unless the rep asks. Don't share sequences or change Admin Settings.
- Never resize, maximize or minimize the LIVE CONTROL window or the Presenter Screen.
- Never start a screen share. That's the rep's call.
- Give every prompt on a page its own wording. Two prompts with identical text on the same page can merge into one when saved.
- When you're done, list every change by prompt number and page.
